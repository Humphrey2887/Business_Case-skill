# 恒力集团 AI 化转型 · 痛点业务化精修（步骤 05）

**P-1（收率寻优依赖人工经验）** · 经营结果：成本降低
在炼化装置日常操作与工艺优化中，收率寻优依赖人工经验与离线优化、无法对海量变量实时全流程寻优 → 综合/高价值收率长期低于最优且波动 → 在最大成本项（原料）持续多耗。**代价**：收率低于最优约 0.5~1pct（示意），经海量产能放大对应年化数亿级原料成本损失。

**P-2（全链排产协同不足）** · 成本降低
炼化-PTA-聚酯全链排产依赖人工、跨装置协同滞后 → 中间物料损耗与收率损失 → 一体化协同红利未充分兑现。**代价**：一体化规模优势打折（示意·待回填）。

**P-3（原油掺炼与采购择时靠经验）** · 成本降低
原油配比与采购择时依赖经验、对劣质化与价差窗口适应不足 → 采购单价与掺炼经济性未最优 → 占成本 80%~85% 的最大成本项优化空间流失。**代价**：最大成本项上每单位价差改善绝对值巨大，未被充分捕捉（示意）。

**P-4（用能调控与公用工程未全局寻优）** · 成本降低
蒸汽/电/热平衡依赖人工、缺全局协同寻优 → 单位综合能耗偏高 → 抬高能源成本、加大能耗双控压力。**代价**：单位综合能耗偏离最优 1~3%（示意）。

**P-5（装置能效漂移难及时发现）** · 运营效率
操作参数非最优、能效漂移缺在线识别归因 → 能耗与产出/质量效率波动延迟发现 → 累积隐性能耗与质量损失。**代价**：隐性成本长期侵蚀现金成本竞争力（示意）。

**P-6（设备故障缺早期预警）** · 风险损失
关键转动/换热设备以定期检修/事后维修为主、缺早期预警 → 非计划停机与维修成本偏高 → 重资产大装置产量损失与安全风险。**代价**：大装置单次非计划停机损失巨大（示意）。

**P-7（质量波动反馈滞后）** · 成本降低
质量以离线抽检为主、工艺参数反馈滞后 → 一次合格率不稳、返工降级报废增加 → 薄利环节现金流被侵蚀。**代价**：返工降级报废增加（示意）。
