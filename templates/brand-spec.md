# 品牌规范（brand-spec）—— 可选覆盖层

> **定位**：本文件是**可选的覆盖层（override）**，不是必填表。
> 默认情况下，PPT 配色与字体由主题色提取工具（`scripts/extract_theme_colors.py`）从**选中母版动态提取**（theme 优先；theme 为 Office 默认色时回退扫描版式页填充色还原品牌色板）。
> **仅当**某客户要求偏离母版默认值时，才在此填写对应项作为覆盖；填了哪项就覆盖哪项，其余继续走母版动态取色。
> 全部留「待填」属正常状态——表示完全采用母版自带配色与字体，无需任何覆盖。

## 配色

| 角色 | 颜色（HEX） | 用途 |
| :-- | :-- | :-- |
| 主色 Primary | `待填` | 标题、主色块、主图表色 |
| 辅色 Secondary | `待填` | 次级元素、辅助色块 |
| 强调 Accent | `待填` | 关键数字、重点标注 |
| 背景 Background | `待填` | 内容页底色 |
| 正文 Text | `待填` | 正文文字 |

## 字体

| 元素 | 字体 | 字号 |
| :-- | :-- | :-- |
| 标题 Header | `待填` | 36-44pt |
| 小标题 | `待填` | 20-24pt |
| 正文 Body | `待填` | 14-16pt |
| 注释/来源 | `待填` | 10-12pt |

## Logo 与版面

- Logo 文件：`待填`（放 `templates/` 下并注明路径）
- Logo 摆放：`待填`（如右上角 / 封面居中）
- 页眉：`待填`
- 页脚：`待填`（如「机密 · 公司名 · 日期」）
- 页码：`待填`（位置/格式）

## 图表风格

- 数据图配色：`待填`（默认用主/辅/强调三色）
- 表格样式：`待填`（如首行主色底、隔行浅色）
- 图标风格：`待填`（如线性/面性、置于彩色圆底）
