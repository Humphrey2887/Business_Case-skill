# PPT 母版（pptx/masters/）

把贵司 **PPT 母版**（`.pptx`）放在本文件夹。

- 调用：「使用 \<名称\> 母版」（按文件名或下方别名表匹配）。
- 约定：**封面 / 目录 / 章节分隔**为固定版式页（生成时直接套用）；内容页样式按 [../../brand-spec.md](../../brand-spec.md) 规范从零搭。
- 母版到位后，会用 `thumbnail.py` 识别各版式页，并把内容页规范回填 brand-spec。
